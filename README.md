# Disclosure

Pre-docket verification for court orders.

Disclosure is an early MVP that forces explicit human interpretation of court orders before deadlines are calendared, producing defensible, source-linked docket entries.

---

## Run locally

Requirements:
- Node.js 18+
- `pdftotext`, `pdfinfo`, and `ocrmypdf` available on PATH

Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

Open: http://localhost:3000
